# The API is unified

The cross-protocol API is called the unified API, as Himalaya's since b21c2d7f (owner, 2026-11-12): its commands, operations, writes and outputs follow, in the code, the `--help` text, the docs and the spec; no behaviour changed. Capabilities moved: commands ("Unified commands stay least-common-denominator"), backends ("Unified operation set", "Unified outputs carry no backend details").
