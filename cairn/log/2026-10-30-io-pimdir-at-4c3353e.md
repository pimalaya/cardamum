# io-pimdir pinned at 4c3353e with the other store tools

io-pimdir moves from `3b4bed8` to `4c3353e`, the revision every pimdir app pins for the stable-release effort (pimdir stable-release plan, Phase A0), so cardamum, himalaya, calendula, neverest and unfog open a store with one io-pimdir. Only the io-pimdir `source` line of Cargo.lock moved. `PimdirAction::Add` gained `supersedes`, which a card create leaves `None`: it supersedes no member. The 0001_init.sql diff is additive and cardamum never opens a store as owner. The staging order stays as it was, producer first, then the body, then the enqueue (src/pimdir/backend.rs, `stage`).

Capabilities moved: none.
